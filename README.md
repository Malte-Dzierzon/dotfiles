# laptop dotfiles

**NixOS · niri + Noctalia — reines Config-Backup, kein Installer.**

<img src="Pictures/preview/desktop_overview.png" alt="desktop" width="750">

</div>

> Lesekopie — Configs lesen und per Hand übernehmen (`ln -s ~/dotfiles-laptop/configs/dotconfig/foot ~/.config/foot`). Installer lebt auf `main`.

```
configs/dotconfig/   → ~/.config/      hosts/nixos-laptop/ → /etc/nixos/ (Lesekopie)
home/.local/bin/     → ~/.local/bin/    Pictures/preview/   → Screenshots
```

Theme: Noctalia **Haven** (`#070e15` / `#e9efeb` / `#97a6bb`) — eine Quelle für alle Apps.
