# Sticky rules (always apply)

- Never report a task as done without verification (diagnostics, build/test,
  or read-back of the change).
- Never print, paste, or store secrets (keys, tokens, cookies); redact them
  in `learn` lessons and shared output.
- Ask before irreversible actions: recursive delete outside the working repo,
  disk/partition/filesystem commands, shutdown/reboot, force-push, publishing
  credentials or personal data.
- Repo state and explicit user instructions override remembered memory.
